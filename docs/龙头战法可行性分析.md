## 一、策略定义：我们说的"龙头"是什么

龙头战法（打板/接力流派）核心是**辨识度 + 情绪周期**，可量化的层次：

| 层次 | 定义 | 可量化指标 |
|------|------|-----------|
| 市场总龙头 | 全市场最高连板、最有人气的票 | 连板高度、封单/流通市值、换手 |
| 板块龙头 | 同行业/概念里最强的那只 | 板块内连板最高、首板最早 |
| 卡位/补涨 | 龙头加速后的跟风 | 板块效应、涨停梯队 |

**纯量化可落地的版本**（不做情绪面）：**高连板 + 强封单 + 早首板 + 板块共振** 的强势股，在"龙头分歧/低吸"位置介入，或做"连板断板反包"。

## 三、因子构建方案（纯标准库可算）

对涨停池每日输出，构建龙头强度分（0-100）：

| 因子 | 权重 | 计算 | 逻辑 |
|------|------|------|------|
| 连板高度 | 30% | log2(连板数) 归一化 | 高度=辨识度，4板>2板 |
| 封板强度 | 25% | 封单资金 / 流通市值（≥5%满分） | 封不死=分歧 |
| 首板时间 | 15% | 09:25=100分，越晚越低 | 早板=资金坚决 |
| 炸板次数 | 10% | 0炸=100，每炸-30 | 炸板=抛压 |
| 板块共振 | 10% | 同 hybk 涨停家数（≥3家满分） | 独苗=伪龙头 |
| 换手/量能 | 10% | 分位换手适中为佳 | 过低=缩量板，过高=出货 |

**信号分级**（对齐现有 S/A/B/C 体系）：
- **S 龙头确认**：连板≥3 + 封板强度≥5% + 首板早于10:00 + 板块≥3家
- **A 龙头候选**：2板 + 强封单 + 板块效应
- **B 观察池**：1板强势（首板10:00前 + 封单大）
- **C 参考**：其余涨停

**两种可回测的入场模式**：
1. **首板打板**（激进）：S 级确认当天尾盘/次日打板 → 依赖次日溢价
2. **断板低吸/反包**（稳健，推荐先做）：高位龙头断板回调至 5/10 日线或前密集区 → 用现有支撑压力 v2 的"接近支撑 + 守住率高"作为买点确认 —— **正好复用今天落地的决策闭环**

## 四、回测验证方案（复用现有框架）

| 环节 | 方案 |
|------|------|
| 股票池 | 涨停池历史回放（东财接口按日拉历史涨停，或用 pool 300 只筛"曾连板"） |
| 样本生成 | 仿 `backtest.py`：非重叠 + 双边成本 0.25% + 剔除一字板买不进/跌停卖不出 |
| 因子验证 | 龙头强度分 vs 未来 1/3/5 日收益（打板是短线，持有期短于均值回归的 10 日） |
| 阈值表 | 按强度分 60/70/80 分组胜率（复用 `threshold_table()`） |
| 市场状态分层 | 涨停家数本身是情绪温度计：**情绪冰点期(涨停<30家)首板胜率高，高潮期(涨停>80家)接力风险大** —— 用涨停家数替代/补充沪深300 状态 |
| 组合回测 | 每日 Top3 龙头等权，次日卖出（复用 `portfolio_backtest.py` 骨架） |

**关键差异点**：龙头策略持有期 1-5 日，需要把 `FORWARD_DAYS` 参数化（现有固定 10 日），且**一字板无法买入必须剔除**（现有 `is_limit_up` 已处理）。

## 五、风险与坑（必须提前知道）

1. **一字板买不进**：龙头最赚钱的阶段往往是一字板，回测"看得见吃不到" → 现有 `is_limit_up` 剔除逻辑已覆盖，但会大幅压缩样本
2. **滑点被严重低估**：打板策略的冲击成本远超 0.25%，情绪票流动性差 → 建议打板模式成本按 1% 双边算
3. **幸存者偏差依旧存在**：涨停池历史数据难免费获取完整，用 pool 300 只回溯会漏掉退市/ST 妖股
4. **情绪周期无法纯技术化**：连板高度是结果不是原因，高位接力的胜率天然低于低位首板 → 建议先做**断板低吸**（配合支撑压力 v2）而非追高
5. **监管风险**：严重异动会被特停，量化追高有合规边界（教学研究用途）
6. **小样本陷阱**：A股每年真正意义的"总龙头"只有 20-30 只，回测样本量天然小，结论置信度低

## 六、分阶段实施建议

| 阶段 | 内容 | 工作量 | 产出 |
|------|------|--------|------|
| **Phase 1** | 抓涨停池落盘 `data/ztpool.json`（每日收盘后，复用 scanner.yml 模式）+ 看板展示今日连板梯队 | 小 | 龙头梯队看板 |
| **Phase 2** | 龙头强度分 + S/A/B/C 信号 + 微信推送（复用现有推送链路） | 小 | 盘中/盘后龙头提醒 |
| **Phase 3** | 断板低吸回测：`连板断板回调至支撑 + 守住率≥60%` 样本验证（复用今天的新支撑压力 v2） | 中 | 回测报告 |
| **Phase 4** | 情绪周期分层（涨停家数温度计）+ 组合回测 | 中 | 完整策略报告 |
| **Phase 5** | （可选）龙虎榜/资金流确认因子 | 大 | 增强版 |

**推荐切入点**：Phase 1 + 3。涨停梯队看板立竿见影，断板低吸是唯一能复用现有支撑压力 v2 决策闭环的龙头玩法，风险收益比最好。

## 七、结论

**可行，且与现有系统契合度高**：
- 数据层 ✅（涨停池接口实测可用，字段全）
- 基建层 ✅（推送/回测/看板全部现成，纯标准库约束满足）
- 策略层 ⚠️ 需谨慎：**不建议做高位打板/接力**（滑点+一字板+情绪周期三重坑），**建议做"断板低吸 + 支撑压力确认"**——龙头辨识度负责选股，支撑压力 v2 的守住率负责择时，正好把今天落地的 P0/P1 用上
- 验证层 ⚠️ 小样本是硬约束，回测结论只能当参考方向，不能当胜率承诺

> 与均值回归策略的关系：龙头战法本质是**动量/情绪策略**，与现有"超跌反弹"（反转策略）天然互补——上涨市做龙头、下跌市做超跌，正好填上现有策略在上涨市的短板（README 回测结论：超跌信号在上涨市失效 46.4%）。
